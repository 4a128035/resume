作品集

AI 整合型 XDR 安全應變平台 (AI-XDR-Project)

Wazuh SIEM & SecOps

主導建置基於 Wazuh Manager VM 的開源 XDR 平台。透過 Syslog/API 整合 SentinelOne EDR 端點威脅與漏洞情報、佈署 Suricata NDR（搭載 Intel 10G SFP+ 光纖網卡監聽 Mirror Port）、以及 FortiGate 資安防護日誌。利用 Python 串接大語言模型（Gemini）對跨設備日誌進行關聯分析，產出具備上下文的 Cyber Kill Chain 威脅應變報告書，大幅縮短事件響應時間。

AI 網路監控與 RCA 診斷系統 (network-monitor-ai)

Python & LLM Agent

開發智慧型網路監控代理人系統，對接 LibreNMS API（設備狀態）、Graylog API（日誌管理）及 UniFi Controller API（即時流量）。當網路發生異常時，系統自動透過 Paramiko (SSH) 登入設備檢索 dmesg 與原始日誌，將多源指標關聯後餵給 Gemini AI 進行「根因分析 (RCA)」與自動化排障建議，並透過 SMTP 發送精準告警報告。

智慧網路拓撲自動 analysis 系統 (topology-analyzer)

Python & vis.js

利用 Python 動態輪詢 LibreNMS 與 UniFi Controller API 抓取骨幹 LLDP 鄰近關係、ARP、FDB (MAC Table) 紀錄。透過雙向 LLDP 智慧去重演算法篩選出網路核心骨幹，產生 100% 現網對接、無重疊的單線化拓撲圖，並使用 vis.js 彈簧佈局前端互動可視化。包含實體連接埠定位器（locate_ip.py），能自動追蹤並排除 Uplink/Trunk 幹線，精確找出任何終端直連的 Edge Port。

MIS 每日 AI 資安晨報機器人 (Security_News_Bot)

Python & Gemini 2.5 Flash

自動化威脅情資監控機器人。每日定時向多個國內外資安 RSS 情資源（iThome、TWCERT、BleepingComputer、HKCERT、Synology、Fortinet-PSIRT）抓取重大漏洞通報。利用 Gemini 2.5 Flash 進行智能翻譯、去重、及「企業資產漏洞匹配」（比對 Windows AD、FortiGate、Synology NAS、VMware 等企業現有資產，精確提高威脅風險判定），每天清晨自動透過安全加密 SMTP（SSL/TLS）將精美的 HTML 晨報派送至 IT 信箱。
